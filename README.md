# Kochplaner

Persönlicher, browserbasierter Wochenplaner: eigene Rezepte, aktuelle Supermarktangebote und eine zusammengefasste Einkaufsliste.

Die Anwendung läuft vollständig im Browser. Eigene Rezepte und manuelle Angebote werden lokal im Browser gespeichert. Automatisch recherchierte Wochenangebote werden beim Neuladen aus der jeweils neu veröffentlichten Version übernommen.

**Live:** https://foerdi1.github.io/kochplaner/
